状态切换规则：
  • 所有状态切换有 0.6秒冷却期，防止抖动
  • 找物品模式会暂停当前导航，保存状态用于恢复
  • AI对话期间切换到CHAT模式，结束后自动恢复导航
状态 说明 触发语音
IDLE 空闲/初始化状态 -
CHAT 对话模式，只返回原始画面 -
BLINDPATH_NAV 盲道导航中 "开始导航"/"盲道导航"
SEEKING_CROSSWALK 寻找并对准斑马线 自动检测到斑马线
WAIT_TRAFFIC_LIGHT 等待红绿灯 对准完成自动进入
CROSSING 正在过马路 "开始过马路"/绿灯
SEEKING_NEXT_BLINDPATH 寻找下一段盲道 过马路结束自动进入
RECOVERY 恢复模式（盲道丢失） 盲道丢失超过阈值
TRAFFIC_LIGHT_DETECTION 红绿灯检测模式 "检测红绿灯"/"看红绿灯"
ITEM_SEARCH 找物品模式 "帮我找一下xxx"

盲道导航关键技术：
  • 光流追踪：使用Lucas-Kanade算法稳定分割mask，减少相机抖动影响
  • EMA平滑：指数移动平均减少mask抖动
  • 中心线提取：自底向上扫描，多项式拟合盲道中心线
  • 避障：YOLO-E开放词汇检测，白名单过滤行人/车辆/障碍物
